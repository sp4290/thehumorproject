User Study 1

User Information
- Relationship to user: Friend
- Prior use of app: Minimal
- Experience with similar apps: Yes (ex. thehumorstudy.org, Tiktok, Instagram)

Observation Context
- Location: Lawn
- Device used: Laptop
- Instructions given: Asked to explore and try voting on memes
- Tasks performed: Logged in, scrolled, voted, explored the upload feature

Three Things the User Liked (Functionality Only)
- Plain design made it easy to focus on content
- Ability to scroll and revisit previous memes to change votes
- The login system saved votes after logging out and back in

Three Areas for Improvement
- Scrolling to vote felt slow compared to flashcard-style interaction
- Hard to precisely click upvote/downvote buttons while scrolling since have to move the cursor
- No clear indication of how many memes remain to vote on

Observed Friction/Confusion
- Hesitated when trying to vote quickly due to button placement
- Unsure if there was a limit to how many memes to scroll through

Behavioral Observations
- Immediately started scrolling before interacting with buttons
- Attempted to vote quickly but slowed down due to cursor accuracy
- Compared experience to flashcard-style apps and expected faster flow

User Quotes
- "It would be faster if these just popped up one by one."
- "I like that I can scroll back though."



User Study 2

User Information
- Relationship to user: Classmate
- Prior use of app: None
- Experience with similar apps: Yes (ex. Tiktok, Instagram)

Observation Context
- Location: Lecture room
- Device used: Laptop
- Instructions given: Asked to log in and try all features
- Tasks performed: Logged in, voted, uploaded image, generated caption

Three Things the User Liked (Functionality Only)
- Ability to vote only after logging in was clear and logical
- Upload and generate feature was easy to access
- “Load More Memes” improved initial page loading speed

Three Areas for Improvement
- Design felt too plain and not engaging
- Multiple captions on similar images felt repetitive
- No feedback or next step after generating a caption

Observed Friction/Confusion
- Unsure what happens after generating a caption
- Confused why similar images appeared with different captions

Behavioral Observations
- Explored upload feature early
- Looked for confirmation or result after generating caption
- Continued scrolling but showed less engagement over time

User Quotes
- "It works, but it feels kind of empty."
- "What happens after I generate this?"



User Study 3

User Information
- Relationship to user: Friend
- Prior use of app: None
- Experience with similar apps: Yes (ex. Instagram)

Observation Context
- Location: Library
- Device used: Phone
- Instructions given: Asked to browse, vote, and explore freely
- Tasks performed: Logged in, voted, scrolled, used load more

Three Things the User Liked (Functionality Only)
- Scrolling allowed flexibility to review and change votes
- Ability to compare multiple captions for the same image
- Load more feature improved speed and reduced wait time

Three Areas for Improvement
- Content did not appear to change frequently, making the experience less engaging over time
- Wanted more control over which memes appear, since meme order and content changed unpredictably, creating inconsistency
- No visibility into past votes like upvote/downvote history

Observed Friction/Confusion
- Noticed unexpected changes in meme order/content
- Uncertainty whether new content was being loaded or recycled

Behavioral Observations
- Scrolled continuously but slowed down as content felt repetitive
- Paid attention to comparing captions on the same image
- Attempted to find patterns in content updates but could not identify any

User Quotes
- "I feel like I’m seeing the same stuff again."
- "It changes randomly."



Final Summary

Key Learnings
- Users value both simplicity and engagement differently
- Voting interaction style (scroll vs flashcards) impacted usability and speed of interaction
- Clear visibility for votes, generated content, and content updates is important for user understanding

Surprises
- Some users preferred scrolling for flexibility, while others found it inefficient
- The same design choice (plain layout, repeated images) was interpreted both positively and negatively
- Content being both repetitive and unpredictably reordered caused confusion rather than variety

Patterns Across Users
- Difficulty with voting interaction while scrolling
- Repetition of content reduced engagement over time
- Desire for more feedback such as vote tracking and generated content results
- Inconsistent or unclear content updates such as order changes and recycled memes caused confusion

Planned Improvements
- Add a flashcard style voting mode as an alternative to scrolling
- Improve content consistency such as reduce repetition and avoid unexpected reordering
- Add voting history and allow users to review past upvotes/downvotes
- Improve caption generation flow by adding generated content directly to the feed or providing confirmation
- Add progress indicator or number of remaining memes
- Add basic analytics like percentage of votes or top memes
