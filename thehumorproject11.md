Summary of Changes

1 Enhanced Account/ Auth UI
Added clear account section with welcome message (username) and logout -> improves clarity of login state

2 Enhanced UI Consistency & Engagement
Redesigned layout with consistent card styling and spacing -> addresses feedback that the app felt plain and empty

3 Enhanced Voting Interaction UI
Enlarged and centered vote buttons -> reduces cursor accuracy issues and supports faster voting

4 Added Flashcard/ Feed Mode Toggle
Introduced flashcard mode (one by one, faster voting) and feed mode (scrollable, revisit votes) -> addresses different user preferences for interaction 

5 Added Voting Progress Indicator
Displayed voted and remaining memes with a progress bar -> resolves uncertainty about how many memes are left 

6 Added Vote History Feature
Showed past votes with totals (votes, upvotes, downvotes) -> improves visibility of user activity, gives the user more control

7 Enhanced Content Loading & Consistency
Implemented step by step loading with “Load More” button -> reduces repetition and prevents random reordering 

8 Enhanced Caption Generation Feedback
Added confirmation messages and displays generated captions -> clarifies post generation flow

9 Enhanced Navigation & Usability
Added mode toggle, vote history access, and scroll controls -> improves overall navigation and user flow
